# 📲 Get ElegAI on your phone — with NO laptop needed to run it

This guide puts **all 3 pieces in the cloud** (all free), so after setup your laptop can be off.
Your phone runs the app on its own. This is a **one-time setup** (~30–40 min, mostly waiting).

```
ElegAI Android app (APK on your phone)
        │  HTTPS
        ▼
ElegAI API  →  https://elegai-api.onrender.com   (Render free tier)
        │
        ▼
MySQL  →  TiDB Cloud Serverless (free, MySQL-compatible, never spins down)
```

---

## Step 1 — Free MySQL in the cloud (TiDB Cloud Serverless)

1. Go to **https://tidbcloud.com** → **Start for Free** (no credit card).
2. **Create a Serverless cluster** (choose any region, e.g. Singapore). Takes ~2 min.
3. When ready, open the cluster → **Connect** → "Connect with a SQL client".
4. Copy the connection details:
   - **Host** e.g. `gateway01.ap-southeast-1.prod.aws.tidbcloud.com`
   - **Port** `4000`
   - **Username** e.g. `2abc1234.user1` (includes your cluster id)
   - **Password** (create one)
5. In the TiDB dashboard, create a database named **`elegai`** (SQL tab → `CREATE DATABASE elegai;`).

> TiDB is MySQL-compatible and requires TLS — the backend already supports it via `DB_SSL=true`.

## Step 2 — Deploy the backend (Render free tier)

1. Put the project on GitHub (create a repo, upload `elegai-app.zip` contents).
2. **https://render.com** → Sign up free → Dashboard → **New** → **Blueprint**.
3. Connect your GitHub repo. Render reads `render.yaml` and creates the web service.
4. Edit `render.yaml` line `repo:` → set **your** GitHub repo URL (one change!).
5. In the Render dashboard, set these env vars (blueprint marks them as needing values):
   | Key | Value |
   |---|---|
   | `DB_HOST` | your TiDB host |
   | `DB_PORT` | `4000` |
   | `DB_USER` | your TiDB username |
   | `DB_PASSWORD` | your TiDB password |
   | `DB_NAME` | `elegai` |
   | `DB_SSL` | `true` |
   | `JWT_SECRET` | any long random string (auto-generated by Render is fine) |
6. **Deploy** → wait ~5 min. The backend **auto-creates the schema and seeds the catalog** on first boot — no manual SQL needed.
7. Verify: open **`https://<your-service>.onrender.com/api/health`** → should show `{"status":"ok"}`.
   Keep this URL — you'll paste it into the app.

> Render free tier: the service sleeps after ~15 min idle and wakes in ~30 s when opened. Perfect for studying.

## Step 3 — Point the mobile app at your cloud backend

Open **`mobile/src/config.js`** and change:

```js
export const API_BASE = 'https://<your-service>.onrender.com';
```

(This is the ONLY code change. The app now talks to your live cloud backend.)

## Step 4 — Build the Android APK in the cloud (EAS, free, no Android Studio)

**Option A — zero laptop (recommended):**
1. Push the repo to GitHub.
2. **https://expo.dev** → Sign up → Settings → **Access tokens** → create one.
3. GitHub repo → Settings → Secrets → Actions → add secret **`EXPO_TOKEN`** = your token.
4. GitHub → **Actions** tab → **"Build ElegAI APK"** → **Run workflow**.
5. Wait ~10–15 min. The APK download link appears in the run logs.

**Option B — one command on your laptop (also fine):**
```bash
npm install -g eas-cli
eas login
cd mobile
npx expo install expo-dev-client   # optional, for dev builds
eas build -p android --profile preview
```

## Step 5 — Install on your phone

1. Download the `.apk` to your Android phone (link from Step 4).
2. Open it → allow **"Install unknown apps"** when asked.
3. Open **ElegAI** → sign in with `maria@example.com / Customer@123`.

**🎉 Done — your phone runs ElegAI with your laptop off.**

## iPhone? (honest note)

- **Free path:** use **Expo Go** (App Store) — scan the QR from `npx expo start` on your laptop and the
  app runs in Expo Go, pointed at the cloud API. Laptop needed only to start the dev server.
- **Standalone iOS install** requires an Apple Developer account ($99/yr) — no way around it
  on iOS. For now, iPhone users can also use the **PWA** version of the web app.

## After setup — how you study & improve

Your laptop is only needed when you're **writing code** (true for every developer):

```bash
# local dev (everything on your machine, using the local DB):
cd backend  && npm start
cd mobile   && npx expo start     # scan QR with Expo Go → app on phone
```

Change a screen in `mobile/src/screens/`, save → the phone hot-reloads. The API, AI engine and
database are the same in both worlds — what you learn locally applies to your live cloud app.

## The files this guide relies on

| File | Purpose |

| `backend/Dockerfile` + `.dockerignore` | container image for Render/Railway |
| `render.yaml` | Render Blueprint (web service + env vars) |
